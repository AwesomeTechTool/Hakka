## 📌 项目简介 / Overview

### 中文
本项目致力于收集、整理和数字化保存**广东省揭西县河婆街道及其周边地区的客家话（河婆客家话）**的单词与句子语料。河婆客家话作为最具代表性的内陆客家方言之一，承载着丰富的历史文化价值。随着时代变迁，保护母语方言刻不容缓。我们希望通过这个开源仓库，为语言学者、方言爱好者以及后代留存一份珍贵的语音与文字档案。

### English
This repository is dedicated to the collection, organization, and digital preservation of words and sentences from the **Hapho Hakka dialect, spoken in Hepo (Hapho) Township, Jiexi County, Guangdong Province, China**. As a distinct and culturally rich variant of the Hakka language, Hapho Hakka carries profound historical value. In a rapidly changing world, preserving our mother tongue is more urgent than ever. Through this open-source repository, we aim to build a valuable textual and linguistic archive for linguists, dialect enthusiasts, and future generations.

## 🗂️ 语料库结构 / Corpus Structure

仓库主要包含以下核心板块 / This repository mainly consists of:

*   **📊 核心词汇 (Vocabulary)**: 涵盖日常用品、亲属称谓、时间天气、动作情感等分类词汇。
*   **💬 实用句子 (Sentences)**: 包含日常寒暄、惯用熟语、故事叙述以及特定语法现象的例句。
*   **🗣️ 语音档案 (Audio - Optional)**: 计划逐步加入核心词汇的标准河婆话音频。

---

## 🎯 仓库目标 / Repository Goals

1.  **抢救性记录**: 优先收集濒临遗忘的河婆客家话老派地道词汇和俗语。
2.  **标准化拼音**: 探索并使用适合河婆话音系特点的拼音方案进行标注。
3.  **互动与共建**: 激发海内外河婆客家后裔的母语认同，共同参与语料补充。

## 🤝 如何贡献 / How to Contribute

我们非常欢迎您的参与！如果您是河婆客家话发音人、语言学研究者或爱好者，可以通过以下方式贡献：
We warmly welcome contributions! If you are a native Hapho Hakka speaker, linguist, or enthusiast, you can help by:

1.  **提交 Issue**: 发现拼音错误、词义偏差或有新词推荐，请直接提出。
2.  **发起 Pull Request**: 依照格式模板直接修改或增加语料文件。
3.  **录制音频**: 协助录制清晰无噪音的词汇或句子读音。
