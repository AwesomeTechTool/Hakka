## 📌 项目简介 / Overview

### 中文
本项目致力于收集、整理和数字化保存广东省 揭西县 河婆街道、坪上镇、龙潭镇 的客家话（河婆客家话）的单词与句子语料。河婆客家话作为最具代表性的内陆客家方言之一，承载着丰富的历史文化价值。随着时代变迁，保护母语方言刻不容缓。我们希望通过这个开源仓库，为语言学者、方言爱好者以及后代留存一份珍贵的语音与文字档案。
